# Yemen-Educational-platform-
منصة اليمن التعليمية هي منصة رقمية متكاملة تضم موقعًا إلكترونيًا وتطبيقًا للهواتف، توحد الجامعات والمعاهد والمدارس لإدارة المحتوى الأكاديمي، والمحاضرات، والملخصات، والاختبارات، مع خدمات المنح، والوظائف، والبحث الذكي، والترجمة، والذكاء الاصطناعي، ضمن بنية آمنة وقابلة للتوسع وإدارة مركزية بصلاحيات ديناميكية
